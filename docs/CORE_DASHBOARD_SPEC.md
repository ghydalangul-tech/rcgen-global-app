
# CORE DASHBOARD SPEC (RCGEN Global App)

## Purpose
Define dashboard behavior after successful login based on selected portal.

---

## Dashboard Rules

The system must detect:
- Selected portal
- User role
- Permission level

---

## 1️⃣ Core Governance Dashboard

Features:
- Organization overview metrics
- Multi-portal statistics
- Finance summary
- Risk alerts
- Compliance tracker
- Quick navigation to all portals

---

## 2️⃣ Educare (School) Dashboard

Features:
- Student count
- Class overview
- Attendance tracker
- Fees status
- Teacher activity
- Parent communication

---

## 3️⃣ Church Dashboard

Features:
- Members count
- Service schedule
- Tithes & offerings summary
- Event management
- Ministry groups
- Prayer requests

---

## 4️⃣ Foundation Dashboard

Features:
- Beneficiary count
- Feeding scheme stats
- Donations tracker
- Volunteer management
- Project progress

---

## Security Rules

Each dashboard must:
- Only display data for that portal
- Respect role-based permissions
- Log activity for audit
