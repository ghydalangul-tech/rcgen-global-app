# GitHub Automation

Workflows, templates and automation for RCGEN Global App.# RCGEN Global App

A digital platform for RCGEN (Revival Christian Group Children of All Nations).

## Key Features
- Child Registration
- Donations (PayPal, SnapScan, Bank)
- Volunteer Sign-Up
- News & Gallery
- Contact RCGEN (form submissions → info@rcgen.org.za)

## Repository Structure
- apps/mobile/ — Flutter mobile app
- services/api/ — backend APIs
- docs/ — documentation and specifications
- .github/ — GitHub automation
