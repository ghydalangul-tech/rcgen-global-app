# RCGEN Global App – Product Requirements Document (PRD)

## 1. Vision

The RCGEN Global App is a digital platform for Revival Christian Group Children of All Nations (RCGEN) to manage children, donations, volunteers and communication globally.

## 2. Core Modules

### 2.1 Child Registration
- Online child registration form
- Parent details capture
- Class assignment (0–18m, 18–36m, 3–4, 4–5, Grade R)
- Document upload (ID, medical info)

### 2.2 Donations
- PayPal
- SnapScan
- Bank Transfer
- Donation history tracking

### 2.3 Volunteer Management
- Volunteer registration form
- Skills selection
- Background verification status

### 2.4 News & Gallery
- Announcements
- Event photos
- Community updates

### 2.5 Contact RCGEN
- Contact form
- All submissions sent to info@rcgen.org.za

## 3. Future Features

- AI Assistant (RCGEN Core Agent)
- Admin Dashboard
- Financial reporting
- Firebase integration
- Azure AI integration

## 4. Target Platforms

- Android
- iOS
- Web

## 5. Technology Stack (Planned)

Frontend: Flutter  
Backend: Firebase / API  
AI: Azure OpenAI  
Payments: PayPal / SnapScan / Bank
